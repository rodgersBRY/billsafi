## Status conventions

- **Confirmed:** an explicit user decision or product direction carried forward in the accepted discussion summary.
- **Proposed / unresolved:** assistant suggestions without subsequent user confirmation, or details not yet discussed.
- **Superseded:** earlier direction replaced by a later decision.

The available conversation contains summarized/truncated assistant responses. These documents do not reconstruct missing details.

## Maintenance

As important discussions are finalized, update the relevant document and decision log. Record the decision date and source, distinguish proposals from confirmed requirements, and mark replaced decisions as superseded. Never silently promote an unresolved choice into a requirement. These are living specifications, not evidence of an implemented application.
